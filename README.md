# Viji C. — Personal Portfolio

A responsive, no-photo personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — dark navy / electric blue styling and responsive layout
- `script.js` — mobile navigation, active section highlighting and footer year

## Run locally
1. Extract the ZIP file.
2. Open the `viji-portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Replace the `#` GitHub and LinkedIn links with your real profile URLs.
3. Add public GitHub repository/demo links when the projects are ready.
4. Confirm all education, grades, internship details and research metrics against your documents.
5. Add a resume PDF only after the final resume is ready, then link it from the page if desired.

## Publish with GitHub Pages
Create a GitHub repository (for example, `viji-portfolio`), upload the files, then enable GitHub Pages from the repository's Settings → Pages. Select the main branch and root folder. GitHub will provide the published URL.
